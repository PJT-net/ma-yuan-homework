# 唯物史观视角：农民阶级局限性与近代化历史作用
> 课程交互式网页作业｜以太平天国运动案例

## 📖项目简介
本网页运用唯物史观生产力、生产关系、经济基础、上层建筑四大核心范畴，解释近代农民阶级局限性的本质，分析太平天国、义和团等农民运动在中国近代化进程中的双重历史作用。
## ✨创新点
1. 拒绝表层套话，从物质生产方式解释局限性根源，区分唯物史观与英雄史观答题误区
2. 多类型交互式习题：拖拽匹配、单选、多选，即时判分反馈
3. 内容包含：概念讲解、太平天国时间轴、两场农民运动对比表、高频答题误区辨析
4. 内置完整学习通讨论答案 + 同学互评模板，完全匹配课程任务要求
5. 柔和护眼低饱和配色，滚动渐入动画、阅读进度条、侧边悬浮目录，阅读舒适
